# proof-chain-auth (retired)

> **Retired in September 2026.** proof.parkinsad.com is now served by Vercel from the
> `web/` folder of [`proof-app`](https://github.com/mirsadra/proof-app). DNS no longer
> points here and GitHub Pages is switched off for this repo. Nothing here is deployed;
> edit `proof-app/web` instead.

This repo used to serve proof.parkinsad.com on GitHub Pages: the Supabase auth callback,
the Universal Links file, help and the legal pages. All of it now lives in
`proof-app/web`, alongside the landing page.

The app's older domain, `proofapp.site`, is still served by
[`proof-chain-web`](https://github.com/mirsadra/proof-chain-web).
